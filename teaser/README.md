# 로고 리뉴얼 티저 영상

기존 로고에서 2026 리뉴얼 로고로 넘어가는 약 59초 분량의 티저 영상입니다.
모든 장면은 코드로 만든 3D 세트(Three.js)를 실제 조명·그림자로 렌더링하고, 필름 후처리(심도, 모션블러, 연필 외곽선, 흑백 그레이딩, 그레인)를 거쳐 mp4로 만듭니다.

- 완성본: `out/teaser.mp4` (1920×1080, 30fps, 효과음 포함)

## 화풍

- 앞부분은 참고 영상(흑백 톤의 부드러운 3D 음영, 창으로 드는 빛줄기, 얕은 심도, 연필선)을 기준으로 잡았습니다.
- 시대가 지날수록 `mono`(흑백) · `outline`(연필 외곽선) · `paper`(종이결) 값이 줄어들고 색·질감·반사가 살아나, 2010년대 골목에서는 완전히 사실적인 렌더가 됩니다. 시대별 값은 `src/scene_travel.js`의 `ERAS[].st`에 있습니다.

| 0:11–0:23 | 시간 여행 | 종이를 쫓는 카메라로 원시 시대 → 이집트 → 그리스 → 중세 → 산업혁명 → 2010년 도시를 지난다 | `src/scene_travel.js` |
| 0:23–0:36 | 골목 | 그래피티 아티스트가 종이를 잡아 기존 로고를 빠르게 그렸다가, 천천히 고쳐 2026 로고로 완성한다 | `src/scene_alley.js` |
| 0:36–0:40 | 휴대폰 | 행인이 휴대폰을 들고, 카메라가 휴대폰 화면 속으로 들어간 뒤 찰칵 | `src/scene_alley.js` |

공통 코드: `src/film.js`(후처리 파이프라인), `src/kit.js`(인물 리그·종이·소품), `src/core.js`(로고 로더·2D 유틸), `src/main.js`(타임라인).

장면 길이는 `src/main.js`의 `SCENES`에서 조정합니다. 길이를 바꾸면 `audio.py` 맨 위의 장면 시작 시각도 함께 맞춰 주세요.

## 다시 만들기

```bash
cd teaser
npm install
npm run preview          # http://localhost:4173 에서 미리보기 (스페이스: 일시정지, ←/→: 1초 이동, ?t=12.3: 정지 프레임)
python3 audio.py         # 효과음 → out/audio.wav  (numpy 필요)
npm run render           # 전체 프레임 렌더 → out/teaser.mp4  (playwright, ffmpeg 필요)
node render.mjs --shots 5.5,30,50 --sheet   # 특정 시각의 정지 프레임만 확인
node render.mjs --from 23 --to 36 --frames out/frames   # 일부 구간만 다시 렌더
```

GPU가 없는 환경에서는 전체 렌더에 수십 분이 걸립니다. 미리보기는 모션블러 없이 재생됩니다.
