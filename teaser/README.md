# 로고 리뉴얼 티저 영상

기존 로고에서 2026 리뉴얼 로고로 넘어가는 약 59초 분량의 티저 영상입니다.
영상은 코드로 그려지며(2D 캔버스 스케치 + Three.js 3D), 헤드리스 브라우저로 프레임을 뽑아 mp4로 만듭니다.

- 완성본: `out/teaser.mp4` (1920×1080, 30fps, 효과음 포함)

## 장면 구성

| 시간 | 장면 | 내용 | 파일 |
| --- | --- | --- | --- |
| 0:00–0:11 | 비밀 사무실 | 검은 형체가 들어와 앉아 깃펜으로 기존 로고를 그리고, 급히 나간 뒤 바람이 종이를 창밖으로 날린다 (동화풍 스케치) | `src/scene_office.js` |
| 0:11–0:23 | 시간 여행 | 종이가 원시 시대 → 이집트 → 그리스 → 중세 → 산업혁명 → 1920년대 → 1990년을 지난다. 시대가 지날수록 선이 정돈되고 색이 살아난다 | `src/scene_travel.js` |
| 0:23–0:36 | 2010년대 골목 | 그래피티 아티스트가 종이를 잡아 기존 로고를 빠르게 그렸다가, 천천히 고쳐 2026 로고로 완성한다 | `src/scene_alley.js` |
| 0:36–0:40 | 휴대폰 | 행인이 휴대폰을 들고, 화면으로 클로즈업된 뒤 찰칵 | `src/scene_alley.js` |
| 0:40–0:45 | 스캔 | 검은 디지털 화면에 원본 2026 로고가 스캔되듯 나타나고, 지지직거리다 점멸 | `src/scene_alley.js` |
| 0:45–0:59 | 3D 로고 | 단순 로고가 #00ff7f 투명 재질의 3D로 등장 → 여러 구도 → 회전 → 정면에서 2D 로고로 전환 → 글리치 후 암전 | `src/scene_3d.js` |

장면 길이는 `src/main.js`의 `SCENES`에서 조정합니다. 길이를 바꾸면 `audio.py` 맨 위의 장면 시작 시각도 함께 맞춰 주세요.

## 다시 만들기

```bash
cd teaser
npm install
npm run preview          # http://localhost:4173 에서 실시간 미리보기 (스페이스: 일시정지, ←/→: 1초 이동, ?t=12.3: 정지 프레임)
python3 audio.py         # 효과음 → out/audio.wav  (numpy 필요)
npm run render           # 전체 프레임 렌더 → out/teaser.mp4  (playwright, ffmpeg 필요)
node render.mjs --shots 5.5,30,50 --sheet   # 특정 시각의 정지 프레임만 확인
```
