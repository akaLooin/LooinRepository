# 립마크 개인정보처리방침

립마크(Lib Mark)는 한 사람이 자기 할 일·일정·일기를 적으려고 만든 개인용 앱입니다.

## 모으는 정보
- 로그인용 이메일 주소와 비밀번호(비밀번호는 암호화되어 저장되며 앱 운영자도 볼 수 없습니다)
- 앱에 직접 적은 할 일, 일정, 일기, 사진, 프로필
- 구글 캘린더를 연결한 경우: 구글 계정 이메일, 연결을 유지하는 데 필요한 구글 열쇠(refresh token), 연동하도록 고른 캘린더의 일정

## 구글 캘린더 정보를 쓰는 방법
- 사용자가 설정에서 고른 캘린더의 일정만 읽고, 사용자가 일정마다 "구글 캘린더에 올리기"를 고른 일정만 씁니다.
- 구글에서 받은 정보는 립마크 안에서 일정을 보여 주고 양쪽을 맞추는 데에만 씁니다. 광고, 판매, 다른 서비스와의 공유에는 쓰지 않습니다.
- 립마크의 구글 사용자 데이터 사용은 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)(제한적 사용 요건 포함)을 따릅니다.

## 보관과 삭제
- 정보는 Supabase(서울 지역) 데이터베이스에 저장되며, 본인만 읽을 수 있게 막혀 있습니다.
- 설정 → 구글 캘린더 → 연결 끊기를 누르면 구글 열쇠와 연동 기록이 지워집니다.
- 계정을 삭제하면 모든 정보가 지워집니다.
