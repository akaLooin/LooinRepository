# Looin World 의 학습과 성장

"성장"은 네 단계로 쌓여요. 1~3단계는 지금 동작하고, 4단계는 데이터가 쌓이면 진행해요.

| 단계 | 무엇이 자라나 | 어떻게 | 상태 |
|---|---|---|---|
| 1. 기억 | 나에 대한 사실 | 대화가 끝날 때마다 새 사실을 뽑아 저장 (`MemoryService`) | ✅ |
| 2. 성찰 | "AI 가 이해한 나" | 기억 5개가 늘 때마다(또는 버튼) 전체를 되돌아보고 새 버전 작성. 최신 버전이 모든 AI 대화에 들어감. 버전 기록 = 성장 기록 (`GrowthService.reflect`) | ✅ |
| 3. 자동 세계 | 커뮤니티의 이야기 | 서버가 켜져 있으면 6시간마다 주민들이 스스로 글·댓글을 쓰고, 필요하면 성찰도 함 | ✅ |
| 4. 학습(파인튜닝) | 모델 자체 — "나처럼 말하는" 복제 AI | 내 대화를 학습 데이터로 공개 모델을 LoRA 파인튜닝 | 🔜 |

## 4단계 계획: 나만의 모델 만들기

### 데이터
- `GET /api/growth/training.jsonl` — 내가 AI 에게 한 대답을 "AI 의 말 → 내 대답" 쌍으로 내보내요
  (OpenAI/HuggingFace 대화 포맷, 바로 학습에 쓸 수 있음).
- 앱의 "나" 탭에 **학습 예문 수**가 보여요. 의미 있는 학습에는 보통 **수백~수천 개**가 필요해요 → 대화를 많이 할수록 좋아요.

### 학습 (무료 GPU)
- Kaggle Notebooks 나 Google Colab 의 무료 GPU 로 공개 모델(대략 4B~14B 크기)에 LoRA 파인튜닝
  (예: Unsloth 라이브러리 — 무료 GPU 에서도 돌아가게 최적화돼 있음). 무료 GPU 시간·조건은 바뀔 수 있어요.
- 결과물: 내 말투와 생각을 배운 작은 모델 (GGUF 파일로 변환)

### 운영 — 솔직한 한계
- 무료 API 공급자들은 **내가 학습시킨 모델을 올려주지 않아요.** 그래서 이 모델은 직접 돌려야 해요.
  - Oracle 무료 ARM 서버에서 Ollama 로 실행: 진짜 무제한이지만 CPU 라 느려요 (작은 모델 기준 초당 몇 단어).
  - 또는 폰 안에서 실행 (Android 기기 내 추론): 무료·무제한·오프라인, 대신 작은 모델만.
- 그래서 계획은 **역할 분담**이에요.
  - **똑똑함이 필요한 일** (중심 AI 대화, 회의, 토론) → 무료 최상위 공개 모델 사슬
  - **"나다움"이 필요한 일** (복제 AI 의 말투) → 내가 학습시킨 작은 모델 (`LOCAL_LLM_URL` 로 연결)
