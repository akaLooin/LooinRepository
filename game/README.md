# Looin Idle (가제)

횡스크롤 방치형 RPG. 여러 캐릭터를 키우고, 접속하지 않은 캐릭터도 계속 성장하는 구조.
이름·수치·그래픽은 전부 임시이며, 기능이 갖춰진 뒤 원하는 컨셉으로 교체한다.

## 실행

```bash
npm install
npm run dev        # 브라우저에서 개발 (화면 터치/클릭으로 조작. PC는 방향키·Space도 가능)
npm test           # 코어 로직 테스트
npm run build      # dist/ 로 웹 빌드
npm run android    # 웹 빌드 후 android/ 프로젝트에 동기화
cd android && ./gradlew assembleDebug   # APK: android/app/build/outputs/apk/debug/
```

## 구조

| 경로 | 역할 |
| --- | --- |
| `src/core/` | 순수 게임 로직(DOM·렌더러 의존 없음). 데이터, 공식, 실시간 시뮬레이션, 방치 보상 |
| `src/game.ts` | 계정/월드 수명주기, 저장(`SaveBackend`), 방치 보상 연결 |
| `src/render/` | Phaser 렌더러. 코드로 생성한 픽셀 파츠를 관절처럼 부드럽게 움직인다 |
| `src/ui/` | DOM 기반 HUD/창 |
| `android/` | Capacitor 안드로이드 프로젝트 |

### 멀티 전환을 위한 설계

- `src/core`는 브라우저 없이 Node에서 그대로 돌아간다 → 서버가 같은 코드로 보상을 검증/지급.
- 방치 보상(`afk.ts`)은 경과 시간과 캐릭터 상태만으로 계산하는 순수 함수 → 서버 권위로 옮기기 쉽다.
- 난수는 시드 기반(`rng.ts`), 저장은 `SaveBackend` 인터페이스 뒤에 있다 → 로컬 저장을 서버 API로 교체.

## 현재 들어간 것

터치 조작(빈 곳=이동, 몬스터=공격, 나무·광맥=채집, 포탈·NPC·제작대=이동 후 사용), 캐릭터 생성(외형)·최대 4캐릭터,
전직(Lv.10: 전사·궁수·마법사, 원거리 발사체), 몬스터 카드(계정 공용 수집 보너스), 마을 + 사냥터 3곳, 처치 수로 열리는 포탈, 자동 전투/채집(AUTO),
레벨·능력치 4종, 특성(패시브 3종 + 액티브 스킬 2종), 촌장 퀘스트 6개, 채광/벌목 기술, 드롭·가방·장비·판매, 제작대, 방치 보상(최대 12시간), 자동 저장.
