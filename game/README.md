# 테일즈토피아 타이쿤 (Talestopia Tycoon)

옛이야기와 동화의 나라 '테일즈토피아'에서 이야기를 팔아 부자가 되는 방치형 클리커 게임입니다.
장르 공식(두드리기 → 건물 → 장르 선택 → 주문 → 다시 쓰기)은 방치형 게임에서 흔히 쓰는 구조를 따르고,
세계관·이름·수치·문구·그림은 모두 새로 만들었습니다. 다른 게임의 이름, 세력, 업그레이드 목록, 그림은 쓰지 않습니다.

## 실행

- 브라우저로 `game/index.html`을 열면 바로 실행됩니다. (빌드 필요 없음)
- 규칙 테스트: `node --test game/tests/engine.test.js`

## 파일 구성

| 파일 | 역할 |
|---|---|
| `js/data.js` | 건물·장르·개선·명장면·밸런스 수치 (기획자가 주로 고칠 곳) |
| `js/engine.js` | 게임 규칙. 화면과 분리돼 있어 테스트·서버 검증에 재사용 가능 |
| `js/ui.js` | 화면 그리기, 터치 입력, 저장/불러오기 |
| `style.css` | 디자인 (밝은 양피지 / 어두운 밤 테마 자동 전환) |

## 핵심 시스템

1. **금화** — 이야기책을 두드리거나 건물이 자동으로 벌어요.
2. **건물 11종** — 떠돌이 이야기꾼 → 이야기의 나무. 한 채 살 때마다 가격 ×1.14.
3. **개선** — 건물 10/25/50/100/150/200채마다 해당 건물 생산 ×2, 깃펜 계열은 두드리기 강화.
4. **장르 (판본마다 1개)** — 이번 판본에서 금화 5만을 벌면 선택. 영웅담 / 로맨스 / 미스터리 / 우화 / 괴담 / 모험기.
   장르마다 고유 효과, 고유 주문, 전용 개선 3개.
5. **영감 & 주문** — 영감은 초당 0.5 회복(최대 100 + 전설 수). 장르 주문에 사용.
6. **다시 쓰기 (환생)** — 누적 금화로 **전설**을 얻고 처음부터. 전설 = ⌊√(누적 금화 / 10억)⌋, 1개당 생산 +2%.
7. **명장면 (업적)** — 16개, 1개당 생산 +1%, 다시 써도 유지.
8. **오프라인 수익** — 자리를 비운 시간(최대 24시간)의 50%를 지급.
9. **저장** — 10초마다 자동 저장, 저장 코드 복사/불러오기 지원.
