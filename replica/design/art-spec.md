# 그림 규칙 (art spec)

모든 그림은 코드로 그린다(`game/src/render/sprites.ts`). 나중에 그림 파일로 바꿀 때도 같은 texture key와 크기를 지킨다.

## 해상도
- 그림 2픽셀 = 월드 1칸. 화면에는 `ART = 0.5` 배율로 그린다. 2배로 만든 그림은 `HI`에 등록한다.
- 예전 1배 그림(나무·광맥·물건 등)은 Scale2x로 키운 뒤 외곽선 색을 다시 칠한다.

## 캐릭터: 기본 마네킹 + 동작 프레임 + 붙임 지점
캐릭터는 얼굴과 옷이 없는 흰 마네킹 하나를 뼈대로 쓴다(`game/src/render/mannequin.ts`). 다른 플레이어와의 차이는 장비로 만든다.

- **몸(사용자가 준 치비 픽셀 뼈대를 손으로 다시 찍음)**: 확정 시안 `replica/design/mannequin-base.txt`(21×27칸)을 게임에서 그대로 쓴다(`mannequin.ts`의 `BASE_PX`). 대기 자세는 시안과 픽셀 단위로 같다. 다른 동작은 시안을 머리·몸통·팔 2·다리 2 조각으로 나눠, 팔은 어깨, 다리는 엉덩이를 축으로 돌려 붙인다(조각을 다시 그리지 않음). 팔을 떼어낸 자리의 몸통 가장자리는 테두리로 메운다.
- **칠**: 테두리는 검정(`#141016`, 피부색과 무관), 1배 두께. 머리는 대각선 모서리 4곳의 튀어나온 바깥 칸을 깎아 둥글게 보이게 한다(반투명 쓰지 않음). 몸통은 밝은 면·기본·그늘, 팔은 왼쪽 밝게·오른쪽 그늘, 다리는 그늘색.
- **피부색**: 톤 번호로 구워 두고 그릴 때 색을 입힌다. 흰 기본색(`#f4f2ee`)에 연한 색을 섞은 8가지(`SKIN_COLORS`). 나중에 직접 칠하기도 톤 번호 위에 얹으면 된다.
- **프레임**: 44×48, **1배 해상도**(그림 1픽셀 = 월드 1칸, 굵직한 픽셀), 발 기준점 (22, 43). 프레임마다 두 층 — 몸(뒤) 층과 앞팔 층. 무기는 그 사이에 그려 손이 손잡이를 감싼다.
- **붙임 지점**: 프레임마다 앞손·뒷손 위치, 무기 각도, 머리 중심·기울기, 가슴 위치를 기록한다. 무기는 앞손에, 모자는 머리에 붙인다.

| 동작 | 프레임 | 반복 | 쓰임 |
|---|---|---|---|
| idle | 12 | ○ | 숨쉬기(몸 1px 오르내림, 팔 흔들림) |
| walk | 12 | ○ | 걷기(디딤·지나감 자세, 위아래 튐) |
| jump / fall | 3 / 3 | | 공중 |
| swing | 10 | | 근접 공격: 와인드업 → 앞발 디디며 내려치기 → 회복 |
| shoot | 8 | | 활: 겨누고 당겼다 놓기 |
| cast | 8 | | 지팡이: 머리 위로 모았다 앞으로 뻗기 |
| mine / chop | 10 / 10 | | 채광(위에서 찍기), 벌목(옆으로 베기) |
| climb | 8 | ○ | 로프 |
| hurt / dead | 3 / 1 | | 피격, 쓰러짐(화면에서 눕힘) |

키프레임(관절 각도)에 가속·감속을 넣어 여러 장으로 샘플링한다. 원작의 "작고 통통 튀는 몸" 느낌은 살리되, 자세와 타이밍은 새로 설계했다. 확인 페이지: `game/mannequin.html`.

## 색
- 외곽선: 검정이 아니라 이웃 색의 어두운 단계(`lineOf`: 두 단계 어둡게 + 짙은 자주와 섞음).
- 옷·물건 음영: 왼쪽 위에서 빛(`Paint.volume`), 그림자 쪽은 붉은·보라 쪽으로 색상을 튼다(`ramp`).

## 몬스터
- 2배 해상도. 눈은 진한 타원 + 위 큰 하이라이트 + 아래 반사광(캐릭터 눈과 같은 화풍).

## 지형
- 땅 타일 96×48(1배, Scale2x 후 192×96). 풀 끝은 들쭉날쭉, 흙은 깊을수록 어둡게, 돌은 무작위로 흩는다.

### 장비 겉모습 (game/src/render/gear.ts)
- 모자·갑옷은 마네킹과 같은 1배 픽셀 격자로 그린다(테두리 'o' = 검정). 시안 격자(21×27) 기준 붙일 칸(`at`)을 적는다.
- 머리·몸통은 동작 중 돌지 않고 칸 단위로만 움직이므로, 프레임 붙임 정보의 `off`(좌우·위아래·머리 좌우)만큼 옮겨 붙인다.
- 그리는 순서: 몸(뒷팔 포함) → 갑옷 → 모자 → 무기 → 앞팔. 갑옷은 팔이 보이도록 몸통 폭만 덮는다.
- 지금 있는 겉모습: 이끼 모자, 이끼 왕관, 통나무 갑옷.
- 멀티플레이: 들어올 때(join) `gear`로 무기·모자·갑옷 id를 보내고, 바꾸면 `{t:"gear"}`로 같은 맵에 알린다. 받는 쪽은 `remoteGear`로 아는 id·맞는 칸만 그린다. 미리보기: `mannequin.html?hat=hat_moss&armor=armor_log`.

### 몸 방향 (2026-11-25)
- 확정 시안(`mannequin-base.txt`)은 밝은 면이 왼쪽이라, 게임에서 오른쪽을 볼 때 왼쪽을 보는 것처럼 읽혔다.
- 게임에서는 시안을 가운데 축(칸 c → 19-c)으로 좌우 뒤집어 쓴다(`MIRROR`). 팔·다리의 앞/뒤 역할, 관절·손 위치, 장비 그림도 같은 축으로 함께 뒤집는다. 동작(휘두르기 방향 등)은 그대로 오른쪽이 앞이다.
