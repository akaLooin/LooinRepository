# 그림 규칙 (art spec)

모든 그림은 코드로 그린다(`game/src/render/sprites.ts`). 나중에 그림 파일로 바꿀 때도 같은 texture key와 크기를 지킨다.

## 해상도
- 그림 2픽셀 = 월드 1칸. 화면에는 `ART = 0.5` 배율로 그린다. 2배로 만든 그림은 `HI`에 등록한다.
- 예전 1배 그림(나무·광맥·물건 등)은 Scale2x로 키운 뒤 외곽선 색을 다시 칠한다.

## 캐릭터 (참고: 메이플식 2등신, 큰 눈)
| 파츠 | 크기(px) | 기준점 |
|---|---|---|
| 머리 `_head` / 눈 감은 `_head_b` | 38×36 | 목 (0.5, 33/36) |
| 뒷머리 `_hairb` | 38×40 | 목 (0.5, 33/40) |
| 몸통 `_torso` | 24×20 | 아래 가운데 |
| 팔 `_arm` | 9×19 | 어깨 (0.5, 0.1) |
| 다리 `_leg` | 11×20 | 엉덩이 (0.4, 0.05) |

- 얼굴: 오른쪽을 보는 3/4. 볼이 둥글고 턱이 갸름하다. 눈은 템플릿(`EYE_NEAR` 7×7, `EYE_FAR` 5×7): 굵은 위 속눈썹, 위가 진한 홍채, 큰 하이라이트 2×2, 아래 반사광. 볼터치 분홍, 입은 2픽셀.
- 머리카락: 뒤통수 덩어리 + 다발(뿌리→끝으로 가늘어지는 곡선). 위에 겹친 다발의 오른쪽 아래에 짙은 갈래 그늘, 다발 가장자리 그림자, 머리를 두르는 광택 띠.
- 피부 그림자는 채도를 크게 올리지 않는다(분홍-갈색 쪽으로 22%만 섞음). 앞머리 바로 아래 한 줄은 그늘.

## 색
- 외곽선: 검정이 아니라 이웃 색의 어두운 단계(`lineOf`: 두 단계 어둡게 + 짙은 자주와 섞음).
- 옷·물건 음영: 왼쪽 위에서 빛(`Paint.volume`), 그림자 쪽은 붉은·보라 쪽으로 색상을 튼다(`ramp`).

## 몬스터
- 2배 해상도. 눈은 진한 타원 + 위 큰 하이라이트 + 아래 반사광(캐릭터 눈과 같은 화풍).

## 지형
- 땅 타일 96×48(1배, Scale2x 후 192×96). 풀 끝은 들쭉날쭉, 흙은 깊을수록 어둡게, 돌은 무작위로 흩는다.
