# 게임 진행 흐름 — 원작 방식 대응표

원작(그랜드체이스 PC)의 **진행 순서와 콘텐츠 구성**을 기준으로 우리 게임의 흐름을 맞춘다.
화면의 생김새·이름·연출은 테일즈토피아식으로 다르게 한다. 원작 쪽 내용은 공개된 플레이 정보 기준의 요약이다.

## 한 판의 흐름

| # | 원작 | 테일즈토피아 RPG | 상태 |
| --- | --- | --- | --- |
| 1 | 실행 → 로그인 → 서버 선택 | 시작 화면 → "이어서 읽기 / 처음부터" (오프라인이라 로그인·서버 없음) | 구현. 로그인·서버는 온라인 단계 |
| 2 | 캐릭터 선택(언제든 교체) | 등장인물 선택 — 열람실·대기실에서 언제든 교체 | 구현 (플레이 가능 1명) |
| 3 | 로비: 모드 선택 (던전 / 대전 / 광장) | 열람실(광장 겸 허브) + 책 지도 위 모드 탭: 모험 / 영웅 던전 / 대전 | 모험만 열림 |
| 4 | 월드맵: 대륙 → 던전 선택 | 책 지도: 책(=대륙) → 장(=던전) 선택, 이전 장 클리어로 해금 | 구현 (책 1권·장 3개) |
| 5 | 방 만들기/참가 → 대기실(최대 4인, 난이도, 캐릭터 변경, 준비/시작) | 대기실: 파티 4자리(지금은 혼자), 난이도, 인물 교체·장비·스킬·상점 바로가기, 출발 | 구현. 2~4번 자리는 온라인 단계 |
| 6 | 로딩 화면 | 로딩: 장 이름 + 도움말 | 구현 |
| 7 | 던전: 스테이지 진행 → 분기 → 보스 | 페이지 진행 → 갈림길 → 보스 | 구현 |
| 8 | 결과: 랭크·경험치·보상 상자 선택 | 결과: 랭크 도장·EXP·골드·장비·보상 카드 | 구현 |
| 9 | 대기실로 복귀 → 다시 시작 | "대기실로"(기본) / 다시 펼치기 / 열람실로 | 구현 |

## 로비에서 할 수 있는 것 (성장·관리)

| 원작 기능 | 우리 게임 | 상태 |
| --- | --- | --- |
| 내 정보·장비 | 캐릭터·가방 | 구현 |
| 스킬 트리 | 스킬 | 구현 |
| 강화 | 제본대 | 구현 |
| 상점 | 매점 | 구현 (게임 재화만) |
| 펫 | 바구니 | 구현 (1종) |
| 미션 | 사서장 · 열람 일지 | 구현 (8개) |
| 출석 보상 | 하루 1회 출석 보상, 7일째마다 추가 보상 | 구현 |
| 전직 | 전직 미션 → 2~4차 | 미구현 (캐릭터 확정 후) |
| 대전(PvP) | 대전 탭 | 온라인 단계 |
| 길드·친구·채팅 | — | 온라인 단계 |
| 영웅/이벤트 던전 | 영웅 던전 탭 | 콘텐츠 확장 단계 |
| 캐시샵·가챠 | — | 온라인 이후 별도 설계 |

## 화면 이동도

```
시작 화면 ─ 등장인물 선택 ─ 열람실(허브) ─┬─ 캐릭터·가방 / 스킬 / 강화 / 상점 / 펫 / 미션 / 옵션
                                          └─ 책 지도 [모험 | 영웅 던전 | 대전]
                                               └─ 대기실 ⇄ (인물 교체·장비·스킬·상점)
                                                    └─ 로딩 ─ 던전 ─ 결과 ─┬─ 대기실 (기본)
                                                                           ├─ 다시 펼치기
                                                                           └─ 열람실
```
