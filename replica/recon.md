# Recon map: Realm Grinder (Android / Steam / Web)

Scope: 게임 시스템 전체의 **기능·구조·흐름** — 초반 판(첫 환생 전)부터 환생·연구·유물까지. 원작의 이름·캐릭터·그림·문구는 가져오지 않고, 각 시스템마다 테일즈토피아 쪽 대응 이름을 붙인다.
For: Looin — 테일즈토피아 타이쿤(Talestopia Tycoon) 개발. 원작과 기능을 1:1로 대조하며 이후 수정하기 위한 기준.
Date: 2026-11-08

> 읽는 법: 각 표의 **원작** 칸은 원작 시스템을 설명하는 용어(비교용)이고, **테일즈토피아** 칸이 우리 게임에 실제로 들어갈 이름·표현이다. 우리 이름은 가안이며 `/replica-brand` 단계에서 확정한다.
> 신뢰도: **high** = 공개 출처 2곳 이상 확인, **medium** = 출처 1곳 또는 커뮤니티 글, **guess** = 기억·추정이라 원작 실행으로 확인 필요.

## Core loop

탭과 건물로 금화를 벌고 → 성향과 진영을 골라 그 진영의 업그레이드·주문으로 생산을 키운 뒤 → 퇴위해서 보석(영구 보너스)을 받고 다시 시작한다. 이 순환을 더 큰 리셋(환생 → 승천)이 감싼다.

### 건물 (11단계)

### 주문

원작: 공통 주문 4종(금화 즉시 획득, 탭 강화, 건물 생산 강화, 보석 효과 강화 등) + 진영마다 고유 주문 1종. 마나를 써서 지속 시간 동안 효과. 자동 시전은 우선순위(금/은)와 최소 마나 임계값을 설정할 수 있다.

| 2 | 125 | 6 | 공통 |
| 3 | 600 | 20 | 공통 |

- 가격 증가: 같은 건물 x채째 가격 = 기본가 × **1.15^x** (승천 뒤에는 1.03^x).
- 성향별 건물은 세 성향이 같은 단계면 가격·생산이 같다 (색만 다름: 선=파랑, 악=빨강, 중립=회색).
- 건물 업그레이드: 보유 **5 / 25 / 75 / 150 / 200 / 300 / 400 / 500**채에서 해금. 1~3단계는 +100% → +200% → +300% → +400% → +500%…, 4~10단계는 +100%씩. 가격 예: 1단계 5채 업그레이드 200, 25채 6,580.
- 각 건물의 5채·25채 업그레이드를 사면 **조수**가 1명씩 생긴다 (10종 × 2 = 20명).
- 진영마다 특정 건물을 그 진영 전용 '고유 건물'로 바꿀 수 있다 (R16 이후, 연구 해금).

### 성향과 진영 가입

| 단계 | 비용 |
| --- | --- |
| 선 / 악 성향 증표 | 금화 25,000 |
| 중립 성향 증표 | 금화 10Qa (1e16) + 보석 1B 이상 등 해금 조건 |
| 기본 진영 6종 조약 | 해당 진영 코인 20개 |
| 중립 진영 3종 조약 | 짝이 되는 두 진영 코인 250개씩 (예: 천사+고블린) |
| 프리스티지 진영 (선·악) | 해당 진영 코인 3,000개 |
| 용병 | 50Spd 금화 (후반) |

- 진영마다 업그레이드 **3단계 × 4개 = 12개** (용병은 4×4). 각 단계의 첫 번째는 조약 → 우호 협정 → 동맹 순서로 사야 다음 것이 열린다.
- 성향 효과: 선 = 능동 플레이(주문·탭), 악 = 방치 플레이(건물 생산), 중립 = 혼합.

### 진영 코인

- 배경을 탭할 때 **기본 10%** 확률로 발견, 조수도 자동으로 모은다. 보석이 많을수록 확률이 오른다(증가 폭은 점점 줄어듦).
- 종류 8개: 기본 6진영 + 프리스티지 선·악 2진영. 중립 진영은 짝 진영 2종 코인을 쓴다.
- 쓰는 곳: 진영 가입·진영 업그레이드·왕실 교환·연구 등.

### 탭과 조수

- 탭 1회 = 금화 1 (업그레이드 없을 때).
- 조수 1명 = 1초마다 탭 보상의 **5%** 를 벌고 진영 코인도 찾는다 (탭 횟수 통계에는 안 들어감).

### 리셋

- **퇴위**: 보석 n개에 필요한 이번 판 누적 금화 = **n(n+1)·5e11** (첫 보석 1T, 다음 +2T, +3T …). 보석 ≈ √(금화 / 5e11).
  유지: 해금된 진영, 보석, 업적과 업적 업그레이드, 완료한 도전, 유물, 루비, 진영별 동맹 횟수 통계, 프리미엄 업그레이드. 나머지는 초기화.
- **환생**: 첫 환생은 보석 **1e27**, 이후 매번 ×1000. 보석·발굴·통계 초기화, 업적·해금 유지. '환생의 힘' 업그레이드를 받는다:
  R1 기준 전체 생산 +50%·x, 오프라인 생산 +500%·x, 진영 코인 확률 +x%, 마나 회복 증가 (x = 환생 횟수). R2부터 보석 보너스 증가, R4·R14·R16 등에서 새 기능 해금.
- **왕실 교환**: 진영 선택 후 업그레이드 탭 첫 칸에 등장. 1회당 모든 건물 생산 +10% (합산). 다음 교환 비용 = floor(20 × 1.1^x) 진영 코인.
