# 아트 규격서 — 테일즈토피아 RPG

그림 파일만 바꿔 넣으면 게임 속 그래픽이 교체되도록 만든 규격입니다.
시트가 없는 캐릭터·몬스터는 지금처럼 코드로 그린 임시 그림이 나오니, **하나씩 차례로** 바꿔 넣어도 됩니다.

## 1. 공통 규칙

| 항목 | 규칙 |
| --- | --- |
| 게임 해상도 | 480×270 (폰에서는 가로가 600 안팎으로 늘어남), 정수 배율로 확대 |
| 형식 | PNG, 투명 배경, 안티에일리어싱 없음 (픽셀 그대로) |
| 방향 | **오른쪽을 보는 모습**으로만 그림. 왼쪽은 게임이 좌우 반전 |
| 외곽선 | 검정 대신 짙은 남보라 `#1b1530` |
| 팔레트 | 책마다 32색 안팎 + 공용 UI 16색. 기본 색은 `game/src/ui/tokens.gd` 참고 |
| 도구 | LibreSprite(무료) 또는 Aseprite → "Export Sprite Sheet"(격자, 여백 없음) |
| 저작권 | 원작이나 다른 게임의 그림을 따라 그리거나 참고 이미지로 겹쳐 쓰지 않음 |

## 2. 스프라이트 시트 구조

- 한 칸 = 한 프레임, **가로 줄 = 애니메이션 하나**
- 모든 칸 크기가 같아야 함
- **기준점(origin)** = 발이 땅에 닿는 점. 모든 프레임에서 같은 자리에 발이 오도록 그림

### 플레이어 캐릭터 (칸 48×48, 기준점 24,44)

| 줄 | 애니메이션 키 | 프레임 | 설명 |
| --- | --- | --- | --- |
| 0 | `idle` | 2~4 | 숨쉬기 |
| 1 | `run` | 4~8 | 달리기 |
| 2 | `air` (칸 0) / `dash` (칸 1) | 각 1 | 점프·낙하 / 대시 |
| 3 | `atk` | 3 | 준비 → 휘두름(판정 나는 순간) → 마무리. 게임이 공격 단계에 맞춰 자동으로 고름 |
| 4 | `hurt` (칸 0) / `down` (칸 1) | 각 1 | 피격 / 쓰러짐 |

확장 예정: 콤보 타수별 공격(`atk_g1`~`atk_g4`), 필살기 3종, 공중 공격, 기상. 키 이름만 추가하면 됩니다.

### 일반 몬스터 (칸 24×20 / 32×32 / 48×48 중 몸집에 맞게)

| 줄 | 키 | 설명 |
| --- | --- | --- |
| 0 | `idle` | 대기 |
| 1 | `run` | 이동 |
| 2 | `atk` | 공격 예고 + 공격 (예고 프레임은 눈·무기가 빨갛게 빛나게 → 피할 타이밍 신호) |
| 3 | `hurt` (칸 0) / `down` (칸 1) | 피격 / 쓰러짐 |

### 보스 (칸 96×96 ~ 160×160)
패턴마다 줄을 하나씩(`swipe`, `slam`, `charge` 등). 보스 연결은 몬스터와 같은 방식이며, 패턴 키는 보스 작업 때 함께 정합니다.

## 3. 게임에 연결하기

1. 시트를 `game/assets/sprites/`에 넣음 (예: `mon_crane.png`)
2. `game/data/sprites.json`에 한 줄 추가:

```json
"mon_crane": {
  "sheet": "res://assets/sprites/mon_crane.png", "frame": [24, 20], "origin": [12, 18],
  "anims": {
    "idle": { "row": 0, "frames": 2, "fps": 6 },
    "run":  { "row": 1, "frames": 2, "fps": 8 },
    "atk":  { "row": 2, "frames": 2, "fps": 8 },
    "hurt": { "row": 3, "frames": 1, "col": 0 },
    "down": { "row": 3, "frames": 1, "col": 1 }
  }
}
```

- `fps`: 초당 프레임 수 (반복 재생)
- `col`: 그 줄에서 몇 번째 칸부터 쓰는지 (기본 0)
- `phased: true`: 공격처럼 게임 판정 단계에 맞춰 프레임을 고름

3. 끝. 판정 상자(히트박스)는 데이터(`attacks.json`)에 따로 있어서 그림 크기와 무관합니다. 옵션의 "판정 상자 표시"로 그림과 판정이 맞는지 확인할 수 있습니다.

## 4. UI 그림

| 파일 | 크기 | 쓰임 |
| --- | --- | --- |
| `assets/ui/panel_dark.png` | 24×24, 9-slice 여백 6 | 어두운 패널 (메뉴) |
| `assets/ui/panel_paper.png` | 24×24, 9-slice 여백 6 | 종이 패널 (지도 카드, 결과) |
| `assets/ui/btn_leather*.png` | 16×16, 여백 4 | 가죽 버튼 (보통/hover/pressed) |
| `assets/ui/btn_ribbon*.png` | 16×16, 여백 4 | 주요 버튼 (리본 빨강) |
| `assets/ui/icon_*.png` | 16×16 | 메뉴·재화 아이콘 16종 |

같은 이름으로 덮어쓰면 바로 바뀝니다. 9-slice = 가운데가 늘어나고 모서리 6픽셀(버튼은 4)은 그대로 유지되는 방식입니다.
