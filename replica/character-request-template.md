- [ ] 4. 쌍검 암살자 · 빠른 연타·회피
- [ ] 5. 자연/변신형 근접
- [ ] 6. 마검사 · 검+마법 혼합
- [ ] 7. 격투/서포트 혼합형
- [ ] 8. 맨손 격투가
