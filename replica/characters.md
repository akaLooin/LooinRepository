# 캐릭터 슬롯 시트 — 원작 역할 → 테일즈토피아 등장인물

원칙: 원작 캐릭터의 **게임 속 역할(포지션·조작 감각·기본 메커니즘 분류)** 만 슬롯으로 가져오고,
그 자리는 **테일즈토피아 등장인물**이 채운다. 외형·이름·성격·사연·대사·스킬 이름/연출·관계도는 원작을 따라가지 않는다.

| 유지해도 되는 것 (장르 공통 요소) | 가져오지 않는 것 |
| --- | --- |
| 근접/원거리/마법 같은 포지션 | 외형(머리색·복장·무기 디자인 조합) |
| 조작 난이도, 콤보 길이, 사거리 감각 | 이름·성격·말투·배경 이야기 |
| "전직하면 무기 계열이 바뀐다" 같은 구조 | 스킬 이름, 필살기 연출 장면, 고유 대사 |
| MP 3단 필살기 체계 | 캐릭터 간 관계(형제·라이벌 등) 설정 |
