> 픽셀 아트 기반 모바일 횡스크롤 액션 RPG. 그랜드체이스의 **게임 시스템과 손맛**을 기준선으로 삼되,

> 작성일 2026-11-25 · 단계: Replica 1단계(recon) 산출물 · 근거 자료: `replica/recon.md`, `replica/features.csv`

## 1. 한 줄 요약

**"손가락 두 개로 즐기는 3층 발판 콤보 액션."** 다층 발판 던전을 뛰어다니며 콤보로 MP를 모으고,
MP 1·2·3단 필살기로 몬스터 무리와 보스를 쓸어버린 뒤, 보상으로 캐릭터를 키운다.

## 2. 원작에서 가져올 것 vs 새로 만들 것

| 구분 | 원작에서 가져오는 것 (기능·규칙) | 우리가 새로 만드는 것 (외형·표현) |
| --- | --- | --- |
| 전투 | 다층 발판, 아래 점프, 2단 점프, 대시, 지상/공중 콤보, 다운·기상 무적, 크리티컬·백어택, MP 3칸 필살기, 반격 | 픽셀 이펙트, 히트스톱/화면 흔들림 연출, 모바일 전용 버튼 체계 |
| 성장 | 레벨·스킬 포인트·스킬 트리, 캐릭터별 전직(1~4차), 장비 7부위, 강화 | 오리지널 직업 이름·컨셉·스킬 이름 |
| 던전 | 지역 → 던전 → 분기 스테이지 → 보스, 난이도, 결과 랭크, 보상 카드 | 오리지널 지역·몬스터·보스 디자인 |
| 동료 | 펫(능력치 + 펫 필살기) | 오리지널 펫 |
| 캐릭터 | 성격이 다른 여러 캐릭터, 계정 공유 인벤토리 | **원작 캐릭터 0명.** 전원 오리지널 |
| 세계관 | — | 완전 새 세계관 (아래 4장) |
| UI | 화면 구성의 정보 항목(HP/MP/콤보 등) | 레이아웃·색·아이콘·폰트 전부 새로 |

**표절 방지 원칙:** 원작 스프라이트·음원·텍스트를 열어 보거나 따라 그리지 않는다. 캐릭터 실루엣·색 조합·무기 종류를 원작 캐릭터와 겹치지 않게 잡는다(예: 붉은 머리 대검 여전사, 녹색 엘프 궁수, 보라색 마법소녀 조합은 피한다). 출시 전 `/replica-brand`의 잔재 검사로 한 번 더 걸러낸다.

## 3. 아트 컨셉 — 픽셀

- **기준 해상도 480×270 (가로)**, 정수 배율 확대(1080p = ×4). 모든 폰 비율은 좌우 여백 대신 배경을 넓혀 대응.
- **캐릭터 스프라이트 48×48 캔버스**(본체 약 24×36), 몬스터 32~64, 보스 96~160.
- **팔레트 제한**: 지역당 32색 + 공용 UI 16색. 외곽선은 검정 대신 어두운 색조(채도 있는 보라·남색)로 → 원작의 3D·애니메풍과 확실히 다르게.
- **표현 키워드**: "등불과 밤하늘" — 어두운 배경 위에 빛나는 타격 이펙트, 필살기는 화면을 픽셀 단위로 갈라내는 컷인.
- **애니메이션 프레임 목표**(캐릭터 1명): 대기 6, 달리기 8, 점프 4, 대시 4, 기본 콤보 4타×4, 공중 공격 4, 피격 2, 다운/기상 6, 필살기 3종×8~12 ≈ **100프레임 내외**.
- 프로토타입 동안은 단색 사각형 + 임시 픽셀(플레이스홀더)로 손맛부터 잡고, 아트는 M3부터 교체.

## 4. 세계관 (오리지널 초안)

하늘에 떠 있는 섬들 **「헤일 군도」**. 섬을 띄우던 별 조각 **'루멘'**이 하룻밤 사이 깨져 흩어졌고,
그 틈으로 빛을 먹는 그림자 **'공허종(空虛種)'**이 스며든다. 플레이어는 루멘 조각을 회수하는 소규모 수색대
**「등불단」**의 신입이 되어 섬을 하나씩 되찾는다.
(이름은 전부 가제. 상표·도메인 검사는 `/replica-brand` 단계에서.)

## 6. 데모 범위

### 들어가는 것 ✅
- **캐릭터 2명** (카이, 노아) + 미르 잠금 카드, 1차 직업 스킬 트리, Lv 1~20
- **지역 1곳 「이끼 등대섬」 · 던전 3개 · 난이도 2단계(보통/어려움)**
  1. 이끼 숲길 — 튜토리얼 겸 첫 던전, 3스테이지, 보스 「뿌리 덩굴 골렘」
  2. 가라앉은 종탑 — 4스테이지, **분기 포탈 1회**, 보스 「녹슨 종지기」
  3. 등대 지하 수로 — 4스테이지, 보스 「등불을 삼킨 장어왕」(2페이즈)
- 일반 몬스터 8종, 보스 3종
- 전투: 이동·점프·아래 점프·대시·콤보·공중 콤보·다운/기상·크리/백어택·MP 3단 필살기·반격·퀵슬롯 포션 2칸·부활
- 결과 화면(S~D 랭크) + 보상 카드 뒤집기
- 장비 6부위(무기·머리·상의·하의·장갑·신발), 등급 4단계, 강화 +0~+5(데모는 파괴 없음)
- 인벤토리(장비/소모/재료), 골드 상점, 펫 1종 「등불여우 포코」
- 마을 허브 1곳, 메인 미션 5개, 대화 박스형 스토리
- 옵션: 사운드·진동·**버튼 위치/크기 편집**, 로컬 저장

### 빠지는 것 ⛔ (이후 단계)
파티 협동·PvP·길드·채팅(온라인 단계), 2~4차 전직, 제작/소켓/세트, 캐시샵·가챠, 영웅/이벤트 던전, 레이드

### 데모 플레이 분량 목표
첫 실행부터 보스 3 클리어까지 **약 60~90분**, 어려움 난이도 반복으로 +60분.

## 7. 모바일 조작 리디자인

원작은 키보드(방향키 + 공격 + 점프, 공격 홀드로 필살기)라 그대로 옮기면 터치에서 손이 꼬인다.

```
┌──────────────────────────────────────────────────────────┐
│ [HP■■■■■■□□] [MP ◆◆◇]   콤보 23        스테이지 2/4  ⏸ │
│                                                          │
│                    (게임 화면 480×270)                   │
│                                                          │
│                                           [MP3][MP2][MP1]│
│   ( 플로팅 패드 )        [포션1][포션2]  [대시]  [점프]  │
│     ← ↑ ↓ →                     [펫]        ( 공격 )     │
└──────────────────────────────────────────────────────────┘
```

- **왼손**: 플로팅 이동 패드. 아래 + 점프 = 아래층으로 내려가기. 위로 빠르게 밀기 = 점프(선택 옵션).
- **오른손**: 큰 공격 버튼 / 점프 / 대시. MP 단계별 **필살기 버튼 3개**는 MP가 찼을 때만 빛남.
- **원작식 옵션**: "공격 길게 누르기로 필살기 충전"을 설정에서 켤 수 있게 둔다(익숙한 유저용).
- 반격: MP 1칸 이상일 때 피격 중 대시 버튼 = 반격.
- 버튼 위치·크기·투명도는 S19에서 드래그 편집. PC 단계에서 키보드/게임패드 매핑으로 그대로 확장.

## 8. 전투 수치 초안 (밸런스 시작점)

| 항목 | 값 |
| --- | --- |
| 게임 로직 틱 | 60Hz 고정 (프레임과 분리 → 나중 온라인 동기화 대비) |
| 히트스톱 | 일반 3프레임, 막타·필살기 6~10프레임 |
| 기상 무적 | 45프레임 (0.75초) |
| MP 충전 | 타격 1회당 약 4%, 피격 시 약 2% → 3칸 = 300% |
| 크리티컬 / 백어택 | 기본 5% · ×1.5 / 뒤에서 타격 시 ×1.2 |
| 결과 랭크 | 시간·피격 횟수·최대 콤보·남은 HP 합산 점수 → S/A/B/C/D |

## 9. 기술 구성 (제안)

| 항목 | 선택 | 이유 |
| --- | --- | --- |
| 엔진 | **Godot 4 (GDScript)** | 무료·오픈소스, 2D 픽셀에 강함, 하나의 코드로 Android → Windows/macOS → iOS 내보내기 |
| 화면 | 480×270 뷰포트, 정수 스케일, 가로 고정 | 픽셀이 뭉개지지 않음 |
| 데이터 | 캐릭터·스킬·몬스터·아이템·던전을 **데이터 파일(JSON/Resource)** 로 분리 | 기획 수치 수정이 코드 수정 없이 가능, 이후 서버로 옮기기 쉬움 |
| 저장 | 기기 로컬 저장(user://) + 버전 필드 | 오프라인 우선, 온라인 도입 시 계정 저장으로 이전 |
| 빌드 | Android APK(테스트) / AAB(스토어) | 사용자 폰에 바로 설치해 확인 |
| 온라인(후순위) | 전투 로직을 "입력 → 결과" 구조로 분리해 두고, 서버 선택은 온라인 단계에서 | 지금 결정하지 않음 |

※ 최종 스택 확정은 다음 단계 `/replica-architect`에서.

## 10. 개발 단계 (한 단계씩, 매 단계 승인 후 진행)

| 단계 | 내용 | 확인 방법 |

| **M0** 기반 | Godot 프로젝트, Android 빌드 파이프라인, 480×270 화면, 입력 체계 | 빈 화면 APK가 폰에서 실행됨 |

| 이후 | PC(키보드/패드) → iOS → 콘텐츠 확장(전직·캐릭터) → 온라인 | — |

## 11. 데모 완료 기준

- 중급 안드로이드 폰(예: 3~4년 된 기기)에서 **60fps 유지**, 터치 입력 지연 체감 없음
- `features.csv`의 `[DEMO]` 항목 전부 `clone=yes`
- 원작 캐릭터·지명·리소스 **0건** (rebrand sweep 통과)
- 처음 실행 후 5탭 이내로 첫 전투 진입

## 12. 확인 받고 싶은 것

1. **가제·세계관**: 「프로젝트 루인 / 헤일 군도 / 등불단」 방향 괜찮은지
2. **데모 캐릭터 2명**(창+방패 카이, 석궁 노아) 구성 괜찮은지 — 원하는 캐릭터 컨셉이 있으면 교체
3. **엔진 Godot 4** 로 가도 되는지 (Unity를 원하면 지금 바꾸는 게 비용이 가장 적음)
4. **조작 방식**: 필살기 버튼 3개(기본) + 원작식 길게 누르기(옵션) 조합 괜찮은지

승인되면 다음 단계는 **`/replica-architect`** — 스택 확정, 데이터 구조(캐릭터·스킬·아이템·던전 스키마), 폴더 구조, M0 작업 순서.
