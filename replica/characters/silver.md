| 항목 | 설계 |

| 기본 콤보 | 4타. 1~3타는 임시 캐릭터보다 판정이 조금 길고(중거리) 살짝 느림, 4타는 크게 베어 띄움 + 히트스톱 길게 |

| MP2 은빛 수호 | 약 1.2초 방어 자세. 그동안 맞으면 피해 0 + 주변 충격파(큰 피해·띄움). 안 맞으면 취소 — **제안: 취소 시 MP 1칸 환불** |

| 패시브 (스킬 트리) | ① 투사체 베기: 공격으로 적 투사체를 지움 ② 기사의 갑옷: 원거리 피해 -15%/레벨(최대 3) ③ 굳건함: 콤보 4타와 필살기 중 슈퍼아머 ④ 금빛 각성: HP 30% 이하가 되면 10초간 공격 +25%·금빛 이펙트(던전당 1회) + 공통 패시브(공격·HP) |
| 전직 | 데모는 1차만. 2~4차는 의뢰서 방향대로 이후 구현(시트에 보존) |

## 확정 사항 (2026-11-26)
- 외형: **B안** (금테 견갑 · 파란 휘장)
- 금빛: 지금은 **금빛 일격** — 근접 공격을 8번 맞히면 다음 공격 하나가 금빛(피해 ×1.6). 패시브 「금빛 일격」으로 필요 타격 수 감소(최소 5타).
- **진짜 금빛 각성**(변신형 패시브)은 3차 「성기사」 전직 때 구현 예정
- **3차 「성기사」 무기: 대검** (2026-11-27 확정) — 장검·방패(2차) → 대검(3차) → 빛으로 만든 검·방패(4차)
- 은빛 수호: 취소되면 MP 1칸 환불
- 스토리 주인공: 실버. 인트로를 "판타지아 가디언즈 리더" 설정으로 다시 씀
- HP 30% 이하 각성 제안은 폐기

## 스킬 트리 v0.9 (1차 「기사」)

- SP: 레벨마다 2, 시작 1 (데모 상한 Lv20 → 41 SP). 전부 찍으려면 165 SP → **고르는 재미**
- 필살기는 MP 칸마다 후보 3개 중 **1개를 장착**. 배우면 빈 칸에 자동 장착, 스킬 화면에서 바꿔 끼움
- 필살기 레벨당 피해 +12%
