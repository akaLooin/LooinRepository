# 캐릭터 시트 — 실버 (슬롯 1 · 근접 입문형)

의뢰서 접수: 2026-11-26 (v1) · 상태: **① 설계 제안 → 확인 대기**

## 의뢰 내용 요약
| 항목 | 내용 |
| --- | --- |
| 이름 / 출신 | 실버 / 판타지아 |
| 소개 | 판타지아를 수호하는 은빛 기사단의 기사단장. 판타지아 가디언즈의 리더 |
| 나이·체형 | 남, 24세, 174cm, 균형 잡힌 체형에 숨은 근육 |
| 외형 | 연노란색 차분한 머리, 탁한 파란 눈, 순수하고 강인한 표정, 투구 없는 은빛 기사 갑옷, 은색 기사 검 |
| 대표 색 | 은색 · 파란색 · 연노란색 |
| 성격 | 당돌함, 낙천적, 긍정적. 도전을 좋아하고 겁을 싫어함 |
| 역할 | 장검 한 자루, 방어 중점 밸런스형 근접 검사. 난이도 쉬움, 거리·속도 중간, 단순하고 묵직한 타격감 |
| 전직 | 기사 → 수호자(검+방패) → 성기사(금빛 각성·빛의 힘) → 블링 나이츠(빛으로 검·방패 생성, 칼날 소환) |

## 게임 설계 제안 (1차 직업 「기사」)

| 항목 | 설계 |
| --- | --- |
| 기본 능력치 | 임시 캐릭터 대비 HP +10%, 방어 +25%, 공격 동일, 이동 속도 -5% → "단단하고 묵직함" |
| 기본 콤보 | 4타. 1~3타는 임시 캐릭터보다 판정이 조금 길고(중거리) 살짝 느림, 4타는 크게 베어 띄움 + 히트스톱 길게 |
| 대시 공격 / 공중 공격 | 어깨로 밀치며 베기 / 내려베기 |
| MP1 은빛 검기 | 전방으로 검기 투사체 발사(관통). 큰 피해 + 맞은 적 **방어력 -30%, 6초** |
| MP2 은빛 수호 | 약 1.2초 방어 자세. 그동안 맞으면 피해 0 + 주변 충격파(큰 피해·띄움). 안 맞으면 취소 — **제안: 취소 시 MP 1칸 환불** |
| MP3 은빛 깃털비 (컷인) | 검을 위로 던짐 → 화면 넓은 범위에 칼날 비(다단히트) → 마지막에 검이 땅에 꽂히며 큰 피해 → 검이 손으로 돌아옴 |
| 패시브 (스킬 트리) | ① 투사체 베기: 공격으로 적 투사체를 지움 ② 기사의 갑옷: 원거리 피해 -15%/레벨(최대 3) ③ 굳건함: 콤보 4타와 필살기 중 슈퍼아머 ④ 금빛 각성: HP 30% 이하가 되면 10초간 공격 +25%·금빛 이펙트(던전당 1회) + 공통 패시브(공격·HP) |
| 전직 | 데모는 1차만. 2~4차는 의뢰서 방향대로 이후 구현(시트에 보존) |

## 확인 필요
1. 외형 시안 A/B/C 중 선택 (`replica/concept/silver-options.png`)
2. MP2 취소 시 MP 1칸 환불 여부
3. 금빛 각성 발동 조건(HP 30% 이하) 괜찮은지
4. 스토리 대사의 주인공을 "견습 사서" → "실버"로 바꾸고, 인트로를 "판타지아 가디언즈 리더로 선발" 설정에 맞게 다시 쓸지
