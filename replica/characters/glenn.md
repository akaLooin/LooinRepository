## 게임 설계 제안 (1차 「사냥꾼」)

| 항목 | 설계 |
| --- | --- |
| 능력치 | 실버 대비 HP -15%, 방어 -20%, 공격 +5%, 이동 비슷 |
| 기본 공격 | 누를 때마다 화살 1발(의뢰서대로 1타). 연타하면 최대 3발까지 빠르게 이어짐, 실버 콤보보다 살짝 느림 |
| 각도 조준 | 이동 패드로 각도 선택: 기본 = 정면, ↑ = 위 45°, 공중에서 ↓ = 아래 45° (의뢰서의 "원하는 각도") |
| 차지 샷 | 공격을 0.6초 누르고 떼면 관통 화살 (필살기 홀드 옵션을 켠 경우에는 필살기 우선) |
| 근접 대응 | 적이 바짝 붙으면 활로 후려치기(밀쳐내기) 자동 — 원거리 캐릭터의 숨 돌릴 틈 |
| 대시 / 공중 | 뒤로 물러서며 쏘기(백스텝 샷) / 공중에서 아래로 쏘기 |
| 꽂힌 화살 | 화살이 맞은 적에게 화살이 꽂혀 쌓임(최대 5), 꽂힌 만큼 받는 피해 증가 — 의뢰서 패시브 아이디어 |

### 스킬 트리 탭 (약 30노드 목표)
- **필살기**: 위 9종
- **사격**: 연사 속도, 차지 샷 강화, 다중 화살(3갈래), 조준 각도 추가(위 60°), 공중 연속 사격
- **사냥**: 은신(몬스터 인식 범위 -30%, 의뢰서), 원거리 보너스(멀리서 맞히면 피해 증가, 의뢰서), 꽂힌 화살 강화(의뢰서), 약점 포착(치명)
- **덫**: 덫 위력·지속시간·설치 수, 수류탄 파편, 덫에 걸린 적 피해 증가

## 확정 사항 (2026-11-28)
- 외형: **B안 숲 사냥꾼** — 눈을 또렷하게(노란 눈동자), 활은 등(볼록한 쪽)이 앞을 향하게 바로 잡음
- 기본 공격: 1발씩, 연타 3발 / 각도 조준(정면 · ↑ 위 45° · 공중 ↓ 아래 45°) / 누르고 있다 떼면 관통 차지 샷
- 필살기 후보 9종 그대로 구현 (마음에 안 들면 이후 교체)
- 근접 밀쳐내기는 **패시브 「활로 후려치기」**로 (사냥 탭)

## 구현 메모
- 클래스 `cls_glenn`, 전용 활 3종(`eq_bow_01~03`, 다른 인물은 착용 불가), 처음 고르면 나무 활·견습 외투 지급
- 꽂힌 화살: 화살이 맞은 적에 최대 5개 쌓이고 개당 받는 피해 +4% (6초 유지)
- 폭발(수류탄·폭발 트랩)은 반경 안의 모든 적에게 피해. 그물은 주변 적까지 묶음
- 스프라이트 15줄(`game/tools/gen_glenn.py`), 초상화 32×32, 스킬 아이콘 31종
- 밸런스(봇 8판, 권장 장비 +2): 2장 Lv4 6/8 · 3장 Lv7 4/8 — 원거리 봇은 사람보다 서툴러 실제로는 더 쉬울 것
