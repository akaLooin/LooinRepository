도구: `app/scripts/sim.ts` — 실제 게임 엔진으로 자동 플레이 (`npx tsx scripts/sim.ts <active|idle> <일수> <초단위> <보고간격초>`)

- **active**: 초당 5회 두드리기, 밝은 이야기 → 음유시인/숲속 친구들, 주문은 쓸 수 있을 때마다
- **idle**: 판 시작 5분만 두드림, 어두운 이야기 → 도적단/유령, 자동 시전 개선을 산 뒤에만 주문
- 공통: 생산/가격 비율이 가장 좋은 건물부터 구매, 개선 전부 구매, 출판 계약은 관문용 조각만 남기고 전부, 퇴위는 "전설 증가가 30분 동안 20% 미만으로 멈췄을 때" (또는 10배 이상일 때)

## 남은 병목 (다음 조정 대상)

1. **판 안에서 생산이 정체**: 건물 1,500채 근처에서 가격(1.15^n)이 생산 증가를 따라잡고, 진영 배율이 x6~x40에서 멈춤. 원작은 주문 조합(숲의 합창 +50,000%, 낭독의 빛 +2,500% 등)과 통계 비례 개선이 판이 길어질수록 커짐.
2. **주문을 거의 못 씀**: 초반 영감 회복 1~5/초, 주문 하나 400~1,000 → 발동 시간 비율이 5~20%. 원작도 비슷하지만 영감 개선(누적 생산 해금)과 진영 영감 개선이 더 빨리 쌓임.
3. **방치 플레이가 active의 1/10 이하**: 자동 시전(누적 영감 6만 해금)이 늦게 열리고, 유령/도적단 시간 비례 효과가 약함. 원작의 어두운 이야기는 방치형으로도 꽤 빠름.
4. **진영 선택 편차**: 숲속 친구들로 돌린 판이 음유시인 판보다 수십 배 약하거나 강함 (진영별 균형 미세 조정 필요).

## 조정 손잡이 (관리자 패널 '기본 수치'에서 바로 바꿀 수 있음)

- 전설 1개당 보너스 `gemBonus` (원작 2%)
- 조각 발견 확률 `fcChance` (원작 10%)
- 견습생 1명당 두드리기 비율 `assistantShare` (원작 5%)
- 오프라인 효율 `offlineRate` (임시 50%)
- 건물 가격 증가율 `costGrowth` (원작 1.15)
- 진영 개선 가격·효과 문장: '진영 개선' 항목
